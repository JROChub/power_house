    COMMAND LINE TOOL

    Install CKODMK 0.2.1.

    The wheel provides the Python command line interface. The source repository is private.

    python -m pip install 'mfenx-ckodmk[optimization] @ https://mfenx.com/ckodmk/downloads/mfenx_ckodmk-0.2.1-py3-none-any.whl' This installs the reproducibly built wheel and the pinned ONNX optimization dependencies directly from MFENX. The source repository is private.
    curl -O https://mfenx.com/ckodmk/downloads/mfenx_ckodmk-0.2.1-py3-none-any.whl.sha256 Verify the wheel against the published checksum before installation.

    SUPPORTED INPUT

    File requirements.

    • ONNX source and candidate files up to 64 MB.
    • Float32 classification input with one model input and one model output.
    • Canonical NPZ data containing Float32 inputs and Int64 labels.
    • Batch size one with no more than 25,000 rows and 250,000 output values.

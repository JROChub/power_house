01 / SYSTEM DEFINITION

What MFENX Local is

a specialized software-defined compute system for local, bounded-memory execution
SYSTEM TYPE

Local software machine

MFENX defines its own instruction set, compiler, work scheduler, storage format, resource certificate, recovery protocol, and verifier. In this release, ordinary CPU threads execute the instructions and local files hold the durable tensors.

CURRENT COMPUTE SCOPE

Exact rank-two i32 matrix multiplication

Local v1 accepts two canonical signed 32-bit integer matrices and computes their product with defined wrapping arithmetic. Other MFENX operations exist elsewhere in the project, but this bounded local release certifies this one manifest-backed operation.

MEMORY MODEL

Durable data is separate from managed RAM

Complete tensors stay in a content-addressed store. The process loads only authenticated chunks, tiles, row buffers, and checkpoint metadata covered by the compiled resource certificate. Data can therefore exceed the admitted managed-memory peak.

CLAIM BOUNDARY

What the release does not claim

MFENX combines compute, storage, recovery, and verification in one software system. This release does not claim a fabricated MFENX processor, a vendor GPU, independent compute nodes, or a TOP500 performance ranking.

03 / EXECUTION PATH

How an execution works

each stage is validated and the result is withheld until exact replay passes
01 IMPORT / CREATE split canonical matrix bytes into BLAKE3-addressed chunks
02 COMPILE validate shapes and emit a digest-bound ISA-v5 image and memory certificate
03 EXECUTE stream bounded tiles through CPU lanes using exact wrapping-i32 arithmetic
04 CHECKPOINT synchronize each output piece and its content-bound receipt before reuse
05 VERIFY / PUBLISH replay every output independently; publish only when all values match
Browser scope

The browser hashes selected acceptance files and, on request, the Linux executable. It does not execute the workload. Measurements were recorded from the operating-system process by the acceptance harness.
